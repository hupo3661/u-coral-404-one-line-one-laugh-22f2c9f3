One funny line for make.fun's "One Line, One Laugh" bounty (140 characters): a password manager that demands you remember the one thing you hired it to remember. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
